# Roadmap

## OSS primitive

- Baseline `.aem` contract
- Python package and CLI
- Validation, privacy checks, density warnings, export/import, manifests
- Optional Hermes reference adapter
- Public docs and examples

## Later work

Future work may include denser encodings, additional adapters, and separate
commercial coordinator layers. Those are not part of the OSS package contract.

Do not use this roadmap to pull private deployment identity, paid-tier licensing,
CRM, pricing, or operator-specific automation into the OSS primitive.
